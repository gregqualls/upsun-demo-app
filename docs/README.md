# Enhanced Metrics Integration Project

## Overview
This project creates a **visually interesting and aesthetically pleasing** interface that demonstrates Upsun's console capabilities for metrics and autoscaling. It's an **interface for creating resource usage** - showcasing how Upsun handles resource management through intuitive, modern UX design.

## Primary Goal
Demonstrate Upsun's metrics and autoscaling capabilities through a professional, intuitive interface that users can interact with to see real-time resource management in action.

## Architecture
- **API Gateway**: Central hub for metrics collection and microservice coordination
- **Microservices**: Individual services with enhanced load generation capabilities
- **Frontend**: React-based dashboard with modern UX and real-time effectiveness indicators
- **Database**: PostgreSQL for metrics storage and historical tracking

## Key Features
- **ScalSun CLI Integration**: Uses Upsun CLI for metrics collection
- **PID Regulator**: Precise CPU load generation
- **Direct Memory Allocation**: Efficient memory load generation
- **Resource-Aware Sliders**: Respects actual Upsun resource limits
- **Real-time Validation**: Measures slider effectiveness against actual metrics
- **Modern UX**: Intuitive, visually appealing interface following modern design principles
- **Effective Demonstration**: Showcases Upsun capabilities through interactive controls
